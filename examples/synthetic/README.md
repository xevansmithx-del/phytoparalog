# Synthetic study fixture

This fixture contains invented identifiers, short artificial sequences, and no archive records. It
is a schema and fail-closed behavior example, not a biological dataset.

The input deliberately labels a family-only reference as `DECLARED_COMPLETE`. That is merely an
unverified input declaration: because the competitive set contains no outsider, PhytoParalog
downgrades the reference to `COMPETITIVE_BACKGROUND_MISSING` and keeps the compilation on hold.
It must not be used as evidence that a family-only reference is complete.

The ToolUniverse setup fixture is separately generated and includes an artificial outsider decoy;
it still remains on hold because no external receipt authority has been established.
